# William Consórcios — site

Site estático publicado no Netlify. Cada push na branch `main` publica automaticamente.

- `index.html` — página principal (configuração no bloco `CONFIG`)
- `blog/` — blog. Novo artigo: criar `blog/<slug>.html` (copiando um existente) e adicionar o item no topo de `blog/posts.js`; incluir a URL em `sitemap.xml`.
